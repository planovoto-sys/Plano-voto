# Dados salvos neste dispositivo e modo offline

Última atualização: 29 de maio de 2026.

O app pode salvar informações no navegador para continuidade do fluxo, funcionamento com pouca conexão e recuperação de rascunho.

## Dados possíveis

- Estado escolhido.
- Progresso do fluxo.
- Candidatos escolhidos.
- Partido, número e notas necessárias para exibição.
- Preferências de filtros.
- Permissões de cookies.
- Cache técnico da PWA.
- Cache de candidatos.
- Snapshot offline mínimo.

Não salvar email, nome ou foto de perfil dentro do snapshot offline.

## Dispositivo compartilhado

Se o usuário usa um dispositivo compartilhado, recomenda-se apagar rascunho local e dados offline ao final do uso.

## Controles

O app deve oferecer apagar rascunho local, apagar dados offline, apagar cache de candidatos, redefinir permissões de cookies e apagar tudo deste dispositivo.
