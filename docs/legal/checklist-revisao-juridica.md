# Checklist de revisão jurídica

Última atualização: 29 de maio de 2026.

- O app deixa claro que não é órgão eleitoral?
- O app deixa claro que não realiza voto oficial?
- O app explica que escolhas podem ser dado sensível?
- Existe controle para apagar dados locais?
- Existe caminho para exclusão de dados da conta?
- Cookies opcionais estão desligados por padrão?
- Marketing e uso comercial exigem consentimento específico?
- O app evita prometer anonimização quando houver risco de reidentificação?
- QR Code temporário está explicado?
- Compartilhamento pelo usuário está explicado?
- Dados offline estão explicados?
- Há canal de atendimento claro?
- Há documentação interna de riscos?
- Há política para incidentes?
- Há revisão de fornecedores?
